Формат каждой темы (три слоя)

Слой Что внутри Пример
Кратко Принцип (1–2 строки) «OSPF — Link-State, алгоритм Дейкстры, Area 0 — ядро»
Схема Визуальная подсказка (ASCII, ваши адреса) [R1] --- Area 0 --- [SW1] --- Area 1 --- [SW11]
Пример Готовый конфиг с кнопкой «Копировать» router ospf 1 / network ... area 0 / area 0 authentication

Покрытие

Уровень Покрытие Комментарий
CCNA 200-301 ~95% Все 6 доменов (Fundamentals, Access, Connectivity, Services, Security, Automation — обзорно)
CCNP ENCOR/ENARSI ~50–55% База есть (OSPF, EIGRP, BGP, MSTP, HSRP, NAT, ACL, NTP, Syslog, troubleshooting). Нет: VRF (детально), multicast, QoS (детально), IP SLA, EEM, SD-WAN, VPN (DMVPN), automation (Python/Ansible)

Ключевые фишки

  • Поиск — фильтрует карточки по всем трём слоям (описание, схема, код).

  • Копирование — чистит !-комментарии (Cisco) и ::-комментарии (Windows), удаляет пустые строки в начале/конце.

  • Тёмно-серый терминал #2b2b2b — как в реальной консоли (не чёрный, чтобы глаза не уставали).

  • Темы — светлая/тёмная, запоминается в localStorage.

  • Офлайн — работает без интернета, без сервера, без зависимостей.
