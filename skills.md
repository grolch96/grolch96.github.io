# Навыки в профессиональной деятельности

## 1. Системное администрирование
*(Домен, групповые политики, фаерволл, маршрутизирование, VLAN, туннели, шифрование, терминалы, почтовые/прокси-сервера, виртуализация, антиспуффинг, слежение за сниффингом, ip-алиасинг, антивирусное ПО)*

### Windows Server (NT - 2012)
- AD (Active Directory)
- GPO (Group Policy)
- DNS, DHCP
- VPN, NAT
- Terminal Server
- Certificate Server
- RADIUS (Cisco Secure ACS)
- Citrix MetaFrame

### Linux (Debian, ASP, Ubuntu, Astra и др.)
- **Iptables + Syslog:** фаерволл, маршрутизатор, билинг.
- **Squid + Sarg + Apache:** кэширующий прокси с тарификацией и списками доступов.
- **FetchMail + Procmail + Popa3d + PostFix:** корпоративный почтовый сервер (статистика, антиспам, внешние ящики).
- **Samba + Winbind + Krb5:** файловый сервер, интеграция с Windows-доменом.
- **Apache + PHP + MySQL + phpMyAdmin:** веб-сервер.
- **OpenVPN + OpenSSL + Lzo, OpenSwan + IPsec, GRE:** туннели с шифрованием.
- **VsFtpd:** FTP-сервер.
- **VirtualBox + PhpVirtualBox + Apache:** виртуализация с веб-управлением.

### Cisco (маршрутизаторы 2801, 2811, 2821)
- Базовое конфигурирование.
- NAT static, dynamic, overload; PAT (проброс портов).
- Router on a stick (маршрутизация VLAN).
- RIP, OSPF, EIGRP.
- ACL (списки доступа).
- IPsec (туннели, шифрование).
- Шейпинг (управление скоростью).
- DNS, DHCP.

### Cisco (коммутаторы 2960, 3560, 3750)
- Базовое конфигурирование.
- VLAN (внедрение в сеть).
- Port Security.
- Стекирование.
- EtherChannel (LACP, PAgP).

### Cisco (точки доступа 1100, 1200, 1300)
- Базовое конфигурирование.
- Мосты (автономные и облегченные системы).
- Шифрование в проводных и беспроводных сетях.

### D-Link (DI-808, DGS-3024, DIR-320, DWL-2100AP и др.)
- Фаерволл, роутинг, туннели, шифрование, VLAN, мосты.

### Avaya (АТС IP 406 Office)
- IP-телефония, роутинг, тарификация.
