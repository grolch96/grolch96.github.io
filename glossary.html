📖 Словарь терминов Cisco

Ключевые термины и определения по сетевым технологиям. Все термины сгруппированы по категориям и связаны с задачами из практикума.

🧱 Базовая терминология и модели

OSI (Open Systems Interconnection)
7-уровневая модель сетевого взаимодействия: физический, канальный, сетевой, транспортный, сеансовый, представления, прикладной. Помогает понять, на каком уровне работает технология (VLAN — L2, OSPF — L3, DHCP — L7).
Теория Уровень: все
TCP/IP
Практическая модель, на которой работает интернет. Состоит из 4 уровней: сетевой доступ, интернет, транспорт, прикладной. В отличие от OSI, это не теоретическая, а реальная архитектура.
Теория Уровень: все
Инкапсуляция
Процесс добавления заголовков при передаче данных вниз по стеку OSI. На каждом уровне добавляется своя служебная информация (например, MAC-адрес на L2, IP-адрес на L3).
Теория Уровень: все
PDU (Protocol Data Unit)
Единица данных на каждом уровне OSI. На L2 это кадр (frame), на L3 — пакет (packet), на L4 — сегмент (segment). Термин помогает точно описывать, что именно передаётся.
Теория Уровень: все

🔀 Коммутация (L2)

VLAN (Virtual LAN)
Технология логической сегментации сети на канальном уровне (L2). Позволяет разделить один физический коммутатор на несколько изолированных «виртуальных» сетей. Клиенты разных VLAN не видят трафик друг друга (без маршрутизации).
L2 Уровень OSI: L2 → Задача 1
Trunk (802.1Q)
Магистральный канал, который передаёт трафик нескольких VLAN по одному физическому линку. Каждый кадр помечается тегом 802.1Q (VLAN ID). Используется между коммутаторами и для связи с роутерами.
L2 Уровень OSI: L2 → Задача 1
Access Port (порт доступа)
Порт коммутатора, который принадлежит только одному VLAN и используется для подключения конечных устройств (ПК, принтеры). Кадры на таком порту передаются без тегов.
L2 Уровень OSI: L2 → Задача 1
EtherChannel (LACP/PAgP)
Объединение нескольких физических линков в один логический канал (Port-Channel). Увеличивает пропускную способность и обеспечивает отказоустойчивость (если один кабель порвётся, канал продолжит работать). LACP — открытый стандарт, PAgP — проприетарный Cisco.
L2 Уровень OSI: L2 → Задача 2, 3
STP (Spanning Tree Protocol)
Протокол, предотвращающий петли на канальном уровне. Если между коммутаторами есть несколько путей, STP выбирает один основной (Root Port) и блокирует остальные (Alternate Port), чтобы кадры не ходили по кругу.
L2 Уровень OSI: L2 → Задача 4
Root Bridge (корневой мост)
Коммутатор, который является «центром» дерева STP. Выбирается по наименьшему приоритету (по умолчанию 32768). Все остальные коммутаторы строят пути к нему. Настройка: spanning-tree vlan 1 priority 24576.
L2 Уровень OSI: L2 → Задача 4
BPDU (Bridge Protocol Data Unit)
Служебные кадры, которыми обмениваются коммутаторы для построения дерева STP. Содержат информацию о приоритете, MAC-адресе и стоимости пути. Если на порт с PortFast приходит BPDU (например, подключили свитч), срабатывает BPDU Guard и порт блокируется.
L2 Уровень OSI: L2
Port Security
Механизм защиты на коммутаторе, который ограничивает количество MAC-адресов на порту и блокирует порт при подключении несанкционированного устройства. Режимы: protect (дропает), restrict (дропает + лог), shutdown (err-disable).
L2 Уровень OSI: L2 → Задача 9
DHCP Snooping
Защита от «левых» DHCP-серверов. Коммутатор проверяет, с какого порта пришёл DHCP-ответ, и пропускает только доверенные (trust) порты. Обычно trust назначается на транк-порту к реальному DHCP-серверу.
L2 Уровень OSI: L2 → Задача 9
MSTP (Multiple Spanning Tree Protocol)
Эволюция STP, которая объединяет несколько VLAN в один «инстанс» (экземпляр) дерева. В отличие от Rapid-PVST+ (где каждый VLAN — отдельное дерево), MSTP создаёт 2–3 дерева для групп VLAN. Снижает нагрузку на CPU и ускоряет сходимость.
L2 Уровень OSI: L2 → Задача 13

🗺️ Маршрутизация (L3)

Маршрутизация (Routing)
Процесс выбора пути для передачи пакета от источника к получателю через одну или несколько сетей. Осуществляется на сетевом уровне (L3) с помощью таблицы маршрутизации.
L3 Уровень OSI: L3
Статический маршрут (Static Route)
Маршрут, заданный вручную администратором. Имеет административную дистанцию (AD) по умолчанию 1 (самый приоритетный). Пример: ip route 192.168.2.0 255.255.255.0 10.0.0.2.
L3 Уровень OSI: L3
Динамическая маршрутизация
Автоматический обмен маршрутной информацией между роутерами с помощью протоколов (OSPF, EIGRP, BGP). Роутеры сами строят таблицу маршрутизации и перестраивают её при изменении топологии.
L3 Уровень OSI: L3
AD (Administrative Distance)
«Вес» источника маршрута. Чем меньше значение, тем приоритетнее маршрут. Значения: Connected = 0, Static = 1, EIGRP = 90, OSPF = 110, RIP = 120. Позволяет выбирать между разными протоколами.
L3 Уровень OSI: L3
Metric (Метрика)
Стоимость пути внутри одного протокола маршрутизации. Например, в OSPF — cost (зависит от пропускной способности), в EIGRP — bandwidth + delay. Чем меньше метрика, тем лучше путь.
L3 Уровень OSI: L3
OSPF (Open Shortest Path First)
Протокол динамической маршрутизации типа Link-State. Строит полную карту сети (LSDB) и вычисляет кратчайшие пути по алгоритму Дейкстры. Работает поверх IP (протокол 89). Поддерживает Multi-Area (разбиение на зоны).
L3 Уровень OSI: L3 → Задача 5
Area (Зона OSPF)
Логическая группа роутеров в OSPF. Area 0 — магистральная (Backbone), остальные зоны подключаются к ней через ABR. Разбиение на зоны снижает нагрузку на CPU и стабилизирует сеть.
L3 Уровень OSI: L3 → Задача 5
ABR (Area Border Router)
Роутер, который находится на границе двух зон OSPF (например, Area 0 и Area 1). Он передаёт маршруты между зонами (LSA Type 3).
L3 Уровень OSI: L3
BGP (Border Gateway Protocol)
Протокол маршрутизации между автономными системами (AS). Используется для обмена маршрутами между провайдерами и корпоративными сетями. Работает поверх TCP (порт 179). Обеспечивает стабильность маршрутов в интернете.
L3 Уровень OSI: L3 (сессия L4) → Задача 7
AS (Autonomous System)
Группа сетей и роутеров под единым управлением (например, провайдер или крупная корпорация). Каждая AS имеет уникальный номер (ASN). BGP используется для связи между AS.
L3 Уровень OSI: L3
EIGRP (Enhanced Interior Gateway Routing Protocol)
Гибридный протокол динамической маршрутизации (проприетарный Cisco, но открыт по RFC 7868). Использует алгоритм DUAL для быстрой сходимости. Поддерживает резервные маршруты (Feasible Successor).
L3 Уровень OSI: L3 → Задача 12
Redistribution (Перераспределение)
Процесс «перелива» маршрутов из одного протокола в другой (например, OSPF ↔ EIGRP). Используется при слиянии сетей с разными протоколами. Требует указания метрики (для EIGRP) и флага subnets (для OSPF).
L3 Уровень OSI: L3 → Задача 12
HSRP (Hot Standby Router Protocol)
Протокол резервирования шлюза (проприетарный Cisco). Два роутера делят один виртуальный IP, который клиенты используют как шлюз. Один активен (Active), другой в режиме ожидания (Standby). При падении Active, Standby мгновенно перехватывает IP.
L3 Уровень OSI: L3 → Задача 6

🌐 Сервисы и NAT

DHCP (Dynamic Host Configuration Protocol)
Протокол прикладного уровня, который автоматически выдаёт клиентам IP-адрес, маску, шлюз и DNS. Работает по схеме DORA (Discover → Offer → Request → Ack) поверх UDP (порты 67 и 68). Избавляет от ручной настройки каждого ПК.
L7 Уровень OSI: L7 (UDP 67/68) → Задача 10
DHCP Pool (Пул адресов)
Диапазон IP-адресов, которые DHCP-сервер может выдать клиентам. Настраивается командой ip dhcp pool ИМЯ, внутри указывается сеть (network), шлюз (default-router) и DNS (dns-server). Исключения задаются через ip dhcp excluded-address.
L7 Уровень OSI: L7 → Задача 10
NAT (Network Address Translation)
Механизм трансляции IP-адресов, который позволяет устройствам с приватными адресами (192.168.x.x) выходить в интернет через один публичный IP. Экономит IPv4-адреса и скрывает внутреннюю структуру сети.
L3 Уровень OSI: L3 → Задача 11
PAT (Port Address Translation)
Разновидность NAT (Overload), которая использует порты для различения сессий разных клиентов. Позволяет множеству внутренних устройств выходить в интернет под одним внешним IP. Настраивается командой ip nat inside source list NAT interface f0/1 overload.
L3/L4 Уровень OSI: L3 (порты L4) → Задача 11
Static NAT
Постоянная трансляция «один-к-одному»: внутренний IP всегда соответствует внешнему. Нужна для серверов, к которым обращаются извне (веб, почта). Частный случай — проброс порта (Port Forwarding): ip nat inside source static tcp 192.168.10.10 80 interface f0/1 80.
L3 Уровень OSI: L3 → Задача 11
ACL (Access Control List)
Список правил, которые разрешают или запрещают трафик на основе IP-адресов, портов и протоколов. Standard ACL фильтрует только по источнику, Extended — по источнику, назначению, протоколу и порту. В конце ACL всегда неявный deny any.
L3/L4 Уровень OSI: L3/L4
NTP (Network Time Protocol)
Протокол синхронизации времени. Позволяет всем устройствам в сети иметь одинаковое время (с точностью до миллисекунд). Критически важно для логов (чтобы сопоставить события), сертификатов и расписаний (cron). Работает поверх UDP (порт 123).
L7 Уровень OSI: L7 (UDP 123) → Задача 14
WLC (Wireless LAN Controller)
Устройство, которое централизованно управляет точками доступа (AP). Позволяет настраивать SSID, шифрование (WPA2/WPA3) и VLAN для всех AP одновременно. Связь с AP осуществляется по протоколу CAPWAP.
L1/L2 Уровень OSI: L1/L2 → Задача 15
AP (Access Point)
Беспроводная точка доступа, которая обеспечивает связь клиентов (ноутбуков, телефонов) с проводной сетью. В корпоративных сетях AP управляется через WLC (CAPWAP), в домашних — работает автономно.
L1/L2 Уровень OSI: L1/L2 → Задача 15
SSID (Service Set Identifier)
Имя беспроводной сети, которое видят клиенты при поиске Wi-Fi. Например, Corp-WiFi. Настраивается на WLC или AP. Может быть скрытым (не транслируется в эфир), но это не даёт реальной защиты.
L2 Уровень OSI: L2 → Задача 15

🛡️ Безопасность

Port Security
Защита порта коммутатора от подключения несанкционированных устройств. Ограничивает количество MAC-адресов на порту. При нарушении порт блокируется (err-disable) или дропает трафик (protect/restrict).
L2 Уровень OSI: L2 → Задача 9
DHCP Snooping
Защита от «левых» DHCP-серверов. Коммутатор проверяет, с какого порта пришёл DHCP-ответ, и пропускает только доверенные (trust) порты. Обычно trust назначается на транк-порту к реальному DHCP-серверу.
L2 Уровень OSI: L2 → Задача 9
DAI (Dynamic ARP Inspection)
Защита от ARP-спуфинга (подмены MAC-адреса). Коммутатор проверяет ARP-пакеты на соответствие легитимной таблице (DHCP Snooping binding). Если MAC не совпадает — пакет дропается.
L2 Уровень OSI: L2
AAA (Authentication, Authorization, Accounting)
Три функции управления доступом: аутентификация (кто ты), авторизация (что тебе можно), учёт (что ты делал). Реализуется через TACACS+ (Cisco, TCP 49) или RADIUS (стандарт, UDP 1812/1813).
L7 Уровень OSI: L7
TACACS+ / RADIUS
Протоколы для централизованной аутентификации. TACACS+ (Cisco) шифрует всё тело пакета и разделяет AAA. RADIUS (стандарт) шифрует только пароль. Для Cisco-сетей чаще используется TACACS+.
L7 Уровень OSI: L7
ACL (Access Control List)
Список правил для фильтрации трафика. Standard ACL (1–99) фильтрует только по источнику. Extended ACL (100–199) — по источнику, назначению, протоколу и порту. В конце ACL всегда неявный deny any.
L3/L4 Уровень OSI: L3/L4

📊 Как пользоваться словарём

1. Поиск: Введите термин в строку поиска (например, «OSPF» или «VLAN»). Словарь отфильтрует карточки и скроет пустые категории.

2. Связь с практикой: У многих терминов есть ссылка → Задача N. Она ведёт на страницу практикума, где этот термин применяется в конкретном сценарии.

3. Уровень OSI: В каждой карточке указан уровень модели OSI, на котором работает технология. Это помогает быстро понять, «где искать» при диагностике.
