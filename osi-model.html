🧱 Модель OSI — Технологии из лабораторных работ

Ниже — интерактивная схема уровней OSI с примерами технологий из Лабораторных работ 1 и 2. Для каждого уровня указано, какие протоколы и технологии там работают, и как они использовались в наших лабораторных.

📌 Зачем это нужно: Понимание модели OSI помогает диагностировать проблемы (на каком уровне искать) и объяснять, как работают технологии. На собеседованиях это один из ключевых вопросов.

7 Прикладной (Application)

Взаимодействие с пользователем и приложениями. Здесь работают DHCP, NTP, SMTP, HTTP, SSH (частично).

DHCP (Лаба 1, 2) NTP (Лаба 2) SMTP (скрипты) HTTP/HTTPS
ip dhcp pool vlan108 network 192.168.8.0 255.255.255.0 default-router 192.168.8.254

6 Представления (Presentation)

Шифрование, сжатие, кодировка. SSH использует шифрование (AES, RSA), TLS/SSL — для HTTPS.

SSH (шифрование) TLS/SSL Кодировки
crypto key generate rsa modulus 1024 ip ssh version 2

5 Сеансовый (Session)

Установка, поддержание и завершение сеансов. BGP устанавливает TCP-сессию, HSRP обменивается hello-пакетами.

BGP (сессия, Лаба 2) HSRP (hello, Лаба 1, 2)
router bgp 65002 neighbor 10.0.0.1 remote-as 65001

4 Транспортный (Transport)

Надёжная (TCP) или быстрая (UDP) доставка. PAT использует порты для различения сессий.

TCP (BGP, SSH) UDP (DHCP, NTP, HSRP) PAT (Лаба 1, 2)
ip nat inside source list NAT interface f0/1 overload

3 Сетевой (Network)

Логическая адресация и маршрутизация. OSPF, EIGRP, BGP, HSRP, NAT, IPv6.

OSPF (Лаба 1, 2) EIGRP (Лаба 2) BGP (Лаба 2) HSRP (Лаба 1, 2) NAT (Лаба 1, 2) IPv6 (Лаба 2) Статические маршруты
router ospf 1111 network 192.168.1.0 0.0.0.255 area 0 ipv6 unicast-routing

2 Канальный (Data Link)

MAC-адресация, коммутация, VLAN, агрегация, защита от петель.

VLAN (Лаба 1, 2) Trunk 802.1Q (Лаба 1, 2) EtherChannel (Лаба 1, 2) STP / Rapid-PVST+ (Лаба 1, 2) MSTP (Лаба 2) Port Security (Лаба 2) DHCP Snooping (Лаба 2)
vlan 100 switchport mode trunk channel-group 1 mode active spanning-tree mode rapid-pvst

1 Физический (Physical)

Кабели, разъёмы, скорость, дуплекс. Физическая передача битов.

Кабели (Ethernet, оптика) Speed 100 / duplex full (Лаба 1, 2) Интерфейсы Fa0/1, Gi0/1 Состояние up/down
interface f0/1 speed 100 duplex full
