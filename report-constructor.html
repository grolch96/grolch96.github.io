Отчет о разработке Конструктора справочников

1. Назначение

Инструмент представляет собой локальный (офлайн) конвертер, который превращает обычные документы Word (.docx) или сохраненные веб-страницы (.html) в интерактивные, красиво оформленные справочники с поддержкой темной темы, поиска и копирования кода.

Вам больше не нужно вручную верстать HTML: вы пишете текст в Word, перетаскиваете файл в окно браузера — и на выходе получаете готовый, стильный файл.

2. Использованные технологии

Технология Где применяется Зачем нужна
HTML5 (File API) Вся страница, drag-and-drop Чтение локальных файлов с диска без отправки на сервер (полная конфиденциальность)
JavaScript (Vanilla) Парсинг HTML, генерация блоков, скачивание Разбор структуры документа, отделение текста от кода, создание файлов на лету
Библиотека mammoth.js Обработка .docx Конвертация бинарных файлов Word в чистый HTML (работает локально, если файл библиотеки лежит рядом)
CSS3 (Grid, Flexbox) Верстка Создание адаптивной сетки, выравнивание элементов, «мягких» скруглений и теней
CSS-переменные (:root) Темы Мгновенное переключение светлой и темной темы без перезагрузки страницы
Backdrop-filter (CSS) Карточки, шапка Эффект «матового стекла» (Glassmorphism) — полупрозрачные блоки с размытием фона
FileReader (с кодировками) Обработка .html Автоматическое определение кодировки (UTF-8 или Windows-1251), чтобы русский текст не превращался в «кракозябры»
Blob API Кнопка «Скачать HTML» Сборка готового файла прямо в браузере и сохранение его на диск

3. Ключевые фишки и эффекты

  1. Три независимых слоя контента:

    • .report-layer — текст, таблицы, картинки (стеклянная карточка с розовым акцентом).

    • .terminal-layer — блоки кода с подсветкой синтаксиса (команды show выделяются желтым, комментарии — зеленым).

    • .ui-layer — панель поиска (появляется только после загрузки файла).

  2. Автоматическая очистка от стилей Word: инструмент принудительно убирает белые фоны и черные буквы, которые Word вшивает в текст. Благодаря этому документ органично вписывается в нашу тему.

  3. Умный поиск: при вводе текста в строку поиска скрываются карточки и блоки кода, в которых нет совпадений.

  4. Кнопка «Копировать»: в каждом блоке кода есть кнопка, которая копирует чистые команды (без лишних символов и комментариев).

  5. Ночная и дневная темы: плавный переход, сохранение выбора в браузере (localStorage), адаптация всех цветов (включая таблицы и код) под выбранный режим.

  6. Офлайн-режим: скрипт не обращается к внешним серверам (если библиотека mammoth.js лежит в папке). Все данные обрабатываются на вашем компьютере.

4. Как это работает (по шагам)

  1. Загрузка: вы перетаскиваете .docx (или .html из Word) в зону загрузки.

  2. Чтение: браузер считывает файл (если DOCX — подключает библиотеку, если HTML — проверяет кодировку).

  3. Парсинг: скрипт разбивает документ на элементы. Блоки <pre> (код) отправляются в терминал, всё остальное — в текстовую карточку.

  4. Верстка: элементы оборачиваются в красивые контейнеры с эффектами и тенями.

  5. Экспорт: по кнопке «Скачать HTML» создается готовый файл, в который вшиваются все стили, скрипты поиска и копирования.

5. Итог

Инструмент решает главную проблему — разрыв между привычным текстовым редактором (Word) и современным веб-дизайном. Теперь вам не нужно быть верстальщиком, чтобы получить красивый, интерактивный и удобный справочник. Достаточно написать текст в Word и перетащить файл в конструктор.
